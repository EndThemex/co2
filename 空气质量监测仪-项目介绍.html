02 / WHY · 为什么做它
看不见的空气，
值得一块 128×64 的屏幕。

密闭的会议室里，CO₂ 一小时就能悄悄越过 1000 ppm——困倦、头胀、走神，都发生在没人知道的时候。TVOC 无色无味，开不开窗全靠猜。当空气变成一个数字、一个等级、一个表情，它才第一次被「看见」。

WHY VISUAL数值化 → 等级化 → 表情化：三步把传感器数据变成一眼可读的状态

04 / METRICS · 监测指标

07 / TOOLING · UI 工具链

UI 与硬件解耦

页面绘制只依赖抽象 Canvas 接口——同一份代码既驱动 OLED，也能在 PC 上预览、校验、迭代。

01
UI 模拟器
ui_sim
同一份页面代码在 PC 上以 ASCII 字模预览：回车切页，也可逐帧回放表情动画。
$ ui_sim --all
02
布局校验
verify_layout.py
ASCII 元素逐像素比对，并检查 5 位数值与 AQI 的最坏宽度是否溢出 64px 栏。
$ python verify_layout.py
03
布局实验台
layout_lab.html
浏览器离线排布 128×64 布局，单文件可用；调好后一键导出 ui_layout.h 写回工程。
→ 导出 ui_layout.h
04
资产生成
gen_cn_font / gen_face_bitmaps
按白名单生成 12×12 中文字模；从 IrisOLED 仓库生成 8 种情绪的表情位图。
$ python tools/gen_cn_font.py
